### What Was Needed

> **Develop a travel-related software app that can be installed on mobile phones to capture trip-related information automatically, enabling NATPAC (National Transportation Planning and Research Centre) to gather large-scale, real-time, and reliable transport data for effective mobility planning.**

---

## 💡 Solution Overview

### TravelIgnition — Automated Travel Data Collection

**TravelIgnition** is an AI-powered mobile application that **automatically collects trip-related data** using GPS, sensors, and Kalman Filter-based smoothing, replacing inefficient manual surveys with real-time, large-scale automated data collection.
